# Finals Tracker

Top-8 finals bracket for a 14-team Sleeper league, with live head-to-head scores and win chances.

- QF1 1v4, QF2 2v3, EF1 5v8, EF2 6v7 → semis → preliminary finals (crossover) → grand final
- Ladder is built from weeks 1 to the chosen ladder week only
- Open Settings to change the league ID or pick an earlier ladder week for a trial run

Hosted with GitHub Pages: a single `index.html`, no build step.
